# Minuteur HIIT

Minuteur d'intervalles pour le HIIT, le Tabata et les circuits : rounds, cycles, bips, voix, flash à l'écran et historique.

Ouvre la page dans Safari, puis Partager > « Sur l'écran d'accueil ». L'appli fonctionne ensuite hors connexion, et les minuteurs restent enregistrés sur le téléphone.

La voix française est générée avec le modèle Kokoro-82M (voix ff_siwis), sous licence Apache 2.0. La police Archivo est sous licence SIL Open Font License.
